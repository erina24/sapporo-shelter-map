# 札幌防災マップ

札幌市の指定避難所を地図上で探せるGIS学習・ポートフォリオ作品です。札幌市のオープンデータから、中央区・北区・東区・豊平区の指定避難所（基幹）を1件ずつ掲載しています。

> 実際の避難判断や避難所の開設状況の確認には、[さっぽろ防災ポータル](https://bousai.city.sapporo.jp/)の最新情報をご確認ください。

## 制作背景

Webエンジニアへのキャリアチェンジに向けてMs.Engineer Bootcampで学ぶなかで、株式会社ラピュールのGISを活用したシステム開発に関心を持ちました。これまで学んだReactとNext.jsを使い、自治体が公開する施設データを地図に載せる過程を通じて、座標の扱い、地図の描画、施設検索の基本を学ぶために制作しました。

## 実装した機能

- 札幌市中心部の地図を表示し、拡大・縮小・移動ができます。
- 施設名の部分一致と区名を組み合わせて検索できます。検索結果は一覧と地図上のマーカーに反映されます。
- 一覧から施設を選ぶと地図がその地点へ移動します。マーカーからも施設名、住所、区名、緯度・経度、施設種別を確認できます。
- PCでは左側に検索・一覧、右側に地図を配置しています。スマートフォンでは検索、地図、一覧を縦に並べています。

## 使用技術

| 技術 | 用途 |
| --- | --- |
| Next.js（App Router）、React、TypeScript | ページ構成、検索条件と選択状態の管理 |
| Tailwind CSS、CSS Grid | 共通の配色と画面幅に応じたレイアウト |
| MapLibre GL JS | 背景地図、マーカー、吹き出し、選択した地点への移動 |
| JSON | 札幌市のCSVから抽出した施設情報の保存 |

## ローカルで動かす

Node.js 20.9以上と npm を用意し、リポジトリのルートで実行します。環境変数とAPIキーの設定は不要です。

```sh
npm ci
npm run dev
```

ターミナルに表示される `Local` のURLを開きます。通常は [http://localhost:3000](http://localhost:3000) です。3000番が使用中の場合は `npm run dev -- --port 3001` でポートを指定できます。背景地図の表示にはインターネット接続とWebGL対応ブラウザが必要です。

```sh
npm run lint
npm run build
```

## 工夫した点

- [ShelterExplorer.tsx](components/ShelterExplorer.tsx) で施設名と区の検索条件を管理し、同じ絞り込み結果を一覧と地図に渡しています。どちらから施設を選んでも、同じ施設IDで詳細を開きます。
- [ShelterMap.tsx](components/ShelterMap.tsx) では地図の初期化、マーカー更新、詳細表示を別の処理に分けています。検索条件が変わったときはマーカーだけを更新するため、操作中の地図を作り直さずに済みます。
- [globals.css](app/globals.css) のCSS Gridで、画面幅に応じて検索・地図・一覧を配置しています。地図のマーカーとズームボタンには44pxの操作領域を設けました。

## 苦労した点と解決方法

- **緯度・経度の順序**。MapLibreは座標を `[経度, 緯度]` の順で受け取ります。[施設データ](data/shelters.json)では `latitude` と `longitude` を名前付きで保存し、マーカーの配置と地図の移動時に、コード上で順序を明示しました。
- **地図の初期化とReactの更新**。初期化のエラーを `useEffect` 内で同期的に状態へ書き込んだところ、Lintで指摘が出ました。表示領域が作られたあとにMapLibreを非同期で読み込み、失敗時にエラー表示へ切り替える構成にしました。

## データの出典

- **施設**。札幌市「避難場所一覧（全区）」CSV（CC BY 4.0、確認日 2026年11月12日）。分類コード2から4件を抽出し、名称・区・所在地・緯度経度・指定区分をJSONに整形しました。座標は原典の値です。 [札幌市のCSV配布ページ](https://ckan.pf-sapporo.jp/dataset/hinanjyo/resource/00af22cb-87c0-4986-a173-171ec7a743e6)
- **背景地図**。国土地理院「地理院タイル（淡色地図）」（利用条件確認日 2026年11月12日）。ブラウザからタイルを取得し、地図上に出典を表示しています。 [地理院タイル一覧・利用条件](https://maps.gsi.go.jp/help/use.html)
